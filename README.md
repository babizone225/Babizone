# 🇨🇮 Babizone — Abidjan Militia

Jeu de tir 2D en vue de côté, inspiré de Mini Militia, dans l'ambiance d'Abidjan : jet-pack, visée à 360°,
4 arènes (Cocody, Abobo, Yopougon, Aéroport), personnages personnalisables, bots, multijoueur local et en ligne.

## Jouer

| Où | Comment |
|---|---|
| **Navigateur (téléphone ou PC)** | Ouvre le lien du jeu (GitHub Pages) et touche l'écran pour démarrer |
| **Windows** | Télécharge `Babizone-windows.zip` dans l'onglet **Releases**, extrais, lance `Babizone.exe` |
| **Depuis le code** | `pip install pygame-ce` puis `python main.py` |

## Commandes

**PC** : Z/Q/D ou flèches = bouger • Z/W/Espace = sauter puis voler • souris = viser • clic = tirer •
R = recharger • E = changer d'arme • **G = ramasser l'arme au sol**

**Mobile** : stick gauche = bouger / voler (vers le haut) • stick droit = viser, poussé à fond = tirer •
boutons R / ARME / PRENDRE / pause

## Tester et nous faire un retour 🙏

Dis-nous : sur quel appareil tu joues, si ça rame, ce qui t'a plu / énervé, et envoie
le fichier `babizone_erreur.txt` s'il y a eu un plantage (version Windows).

## Multijoueur en ligne (PC)

Jouer → Multi en ligne → Héberger → donne le code d'invitation à tes amis.
Même Wi-Fi : direct. À distance : utilise un VPN gratuit (Radmin VPN, Tailscale) et donne l'IP affichée.

## Développement

Python 3 + [pygame-ce](https://pyga.me). Les sons sont générés par `make_sounds.py`.
La version navigateur est construite avec [pygbag](https://pygame-web.github.io), le `.exe` avec PyInstaller
(voir `.github/workflows/`).
